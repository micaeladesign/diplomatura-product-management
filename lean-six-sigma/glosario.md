# Glosario de Lean Six Sigma

Términos del libro *The Lean Six Sigma Black Belt Handbook*, en orden alfabético y con definiciones propias. Entre corchetes, la página de esta sección donde se explica. Para los términos de producto, está el [glosario general](/glosario.md).

| Término | Definición | Dónde |
|---|---|---|
| **3,4 DPMO** | Meta de Six Sigma: 3,4 defectos por millón de oportunidades, contando un corrimiento del proceso de 1,5σ a largo plazo. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **4 C** | Lo que pierde una persona ante un cambio: Comodidad, Confianza, Competencia y Control. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **4 K** | Por dónde empezar Kaizen: lo que huele mal, lo difícil u oscuro, lo sucio y lo peligroso. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **5 Porqués** | Preguntar "¿por qué?" sucesivamente hasta llegar a la causa raíz. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **5M** | Materiales, Máquinas, Mano de obra, Métodos y Mediciones: las entradas y fuentes de variación de un proceso. Con Medio ambiente, son las 6M del Ishikawa. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **5S** | Clasificar, Ordenar, Limpiar, Estandarizar y Sostener: método para organizar el lugar de trabajo. Suele ser lo primero que se implementa en Lean. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **ANOVA** | Análisis de varianza: prueba si los promedios de varios grupos difieren de verdad o por azar. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Análisis de causa raíz (RCA)** | Buscar la causa de fondo de un problema, no el síntoma. Punto de encuentro entre Lean y Six Sigma. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **Benchmarking** | Compararse con los mejores, dentro o fuera de la organización, para adoptar mejores prácticas. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Black Belt (BB)** | Especialista de tiempo completo en LSS que lidera proyectos complejos y apoya a Green Belts. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **Blue Belt** | Nivel básico que debería tener toda la fuerza laboral; sostiene la cultura con mejoras diarias. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **BVA** | *Business value-added*: actividad que no agrega valor al cliente pero es necesaria para operar (contabilidad, normativa). Se minimiza. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Calidad** | Para el libro, cumplir los requisitos del cliente. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **Calidad en la fuente** | Construir la calidad mientras se hace el trabajo, en lugar de inspeccionar al final. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Carta de control** | Gráfico de una medición en el tiempo con límites superior e inferior, para distinguir variación normal de señales reales. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Cp / Cpk** | Índices de capacidad de proceso. Un proceso Six Sigma tiene Cp = 2 y, con el corrimiento de largo plazo, Cpk = 1,5. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **CTQ** | *Critical to quality*: característica que el cliente considera indispensable. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Desperdicio** | Todo lo que el cliente no está dispuesto a pagar. En japonés, *muda*. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **DFSS** | *Design for Six Sigma*: diseñar productos y procesos nuevos con Six Sigma. DMADV es su ruta más conocida. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **Diagrama de dispersión** | Gráfico de dos variables para ver si están relacionadas. Muestra relación, no causa. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Diseño de experimentos (DoE)** | Probar varios factores a la vez de forma planificada para obtener la mayor información al menor costo. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **DMADV** | Definir, Medir, Analizar, Diseñar, Verificar: ruta Six Sigma para diseñar algo nuevo. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **DMAIC** | Definir, Medir, Analizar, Mejorar (*Improve*), Controlar: ruta Six Sigma para mejorar un proceso existente. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **DPMO** | Defectos por millón de oportunidades. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **Dueño del proceso** | Ejecutivo único responsable de un proceso de punta a punta, con autoridad para cruzar áreas. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **FAST** | *Fast-action solution technique*: reunión de 1 o 2 días sobre un proceso que termina con mejoras aprobadas para los siguientes 90 días. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Factores críticos de éxito** | Las pocas cosas que tienen que salir bien o el proceso fracasa. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **Flujo continuo** | Procesar y mover de a una unidad, sin lotes ni esperas. "Hacer uno, mover uno". | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Flujo de valor** | El recorrido completo desde el pedido del cliente hasta que recibe el producto o servicio. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **FMEA** | Análisis de modos de falla y efectos: anticipar cómo puede fallar algo, con qué impacto, y prevenirlo. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **FODA (SWOT)** | Fortalezas, Oportunidades, Debilidades y Amenazas frente a un objetivo. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Gemba** | "El lugar real": donde se crea el valor. Ir al gemba es ir a ver el problema donde pasa. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Gembutsu** | Los objetos y datos reales que rodean un problema en el gemba. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Green Belt (GB)** | Profesional que dedica parte de su tiempo a LSS; lidera proyectos simples o integra equipos. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **Ishikawa** | Diagrama de causa y efecto o espina de pescado: agrupa las causas posibles de un problema por categorías. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Just-in-time (JIT)** | Producir solo lo necesario, cuando se necesita y en la cantidad necesaria. Opuesto al "por las dudas" (*just-in-case*). | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Kaikaku** | Cambio radical o transformación de la mente: Lean deja de ser algo que se aplica y pasa a ser la forma de pensar. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Kaizen** | Cambio + mejora: mejora continua con pasos chicos e involucrando a todos. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Kakushin** | Innovación, entendida como un proceso que se puede gestionar. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Kanban** | Señal visual que dispara la reposición o la producción. Implementa el sistema pull. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **KPIV / KPOV** | Variables clave de entrada y de salida de un proceso. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Lean** | Filosofía operativa para identificar y eliminar todo desperdicio, partiendo de lo que el cliente valora. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **Lean Six Sigma (LSS)** | Combinación de Lean (velocidad, desperdicio) y Six Sigma (calidad, variación). | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **Master Black Belt (MBB)** | Máximo nivel: forma y certifica cinturones y trabaja con la dirección en el cambio cultural. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **MSA** | Análisis del sistema de medición: comprobar que los datos son confiables. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Muda, mura, muri** | Desperdicio, irregularidad (variación) y sobrecarga: las tres "mu" de Toyota. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **NVA** | *No-value-added*: actividad que consume tiempo o recursos sin agregar valor para el cliente. Se elimina. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **OCM** | Gestión del cambio organizacional: método para reducir la resistencia de las personas a cambios importantes. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **OEE** | Eficiencia general del equipo: disponibilidad × rendimiento × calidad. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Pareto** | Gráfico de barras ordenado de mayor a menor que separa las pocas causas vitales de las muchas triviales (regla 80/20). | [Herramientas](/lean-six-sigma/herramientas.md) |
| **PDCA** | Planificar, Hacer, Verificar, Actuar: ciclo de mejora. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Poka-yoke** | A prueba de errores: diseñar para que el error no pueda ocurrir o se detecte en el momento. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Proceso de negocio** | Conjunto de actividades repetibles con entradas medibles, actividades que agregan valor y salidas medibles. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **QFD** | Despliegue de la función de calidad: traduce la voz del cliente en características técnicas. Su matriz es la Casa de la Calidad. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Rendimiento acumulado (RTY)** | Probabilidad de que una unidad salga bien en todos los pasos sin retrabajo; se multiplica el rendimiento de cada paso. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **SDCA** | Estandarizar, Hacer, Verificar, Actuar: ciclo para mantener. Va antes que el PDCA. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Sigma (σ)** | Desviación estándar: mide cuánto se dispersan los resultados alrededor del promedio. | [Sección 3](/lean-six-sigma/seccion-3.md) |
| **SIPOC** | Proveedores, Entradas, Proceso, Salidas, Clientes: mapa de alto nivel de un proceso. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Sistema pull** | Solo se repone o produce lo que el cliente consumió. Opuesto a empujar según pronóstico (*push*). | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Six Sigma** | Estrategia para reducir la variación y los defectos con métodos estadísticos, creada en Motorola. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **SMED** | Cambio rápido de herramental: pasar de un producto a otro en minutos. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Taguchi (función de pérdida)** | Idea de que cualquier desvío del valor objetivo genera una pérdida, aunque esté dentro de la especificación. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Takt time** | Ritmo de la demanda: tiempo neto disponible ÷ demanda del cliente. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Tarjeta roja** | Etiqueta que se pone en la etapa Clasificar de 5S a lo que está "deseado pero no necesario". | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **TOC** | Teoría de las restricciones (Goldratt): todo sistema está limitado por unas pocas restricciones. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **TPM** | Mantenimiento productivo total: que los equipos no fallen, con participación de todos. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **TPS** | Sistema de Producción Toyota, creado por Taiichi Ohno: la base de Lean. | [Sección 1](/lean-six-sigma/seccion-1.md) |
| **Trabajo estandarizado** | Forma acordada y sistemática de hacer una tarea. Base para poder mejorarla. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **VA** | *Value-added*: actividad que transforma material o información para cumplir lo que pide el cliente. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **Variación** | Cómo difieren los resultados de un proceso a lo largo del tiempo. Enemigo principal de Six Sigma. | [Sección 2](/lean-six-sigma/seccion-2.md) |
| **VSM** | Mapa del flujo de valor: dibujo del proceso actual y futuro con tiempos, esperas e inventarios. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Y = f(X)** | El resultado (Y) depende de las causas (X): se observa Y, pero se trabaja sobre las X. | [Herramientas](/lean-six-sigma/herramientas.md) |
| **Yellow Belt (YB)** | Integrante de equipos LSS con formación básica; aporta conocimiento del área y datos. | [Sección 1](/lean-six-sigma/seccion-1.md) |
