# Glosario de Product Management

Términos de la diplomatura en orden alfabético. Entre corchetes, la unidad donde aparece. Usá el buscador del sitio (arriba a la izquierda) para saltar a uno. Los términos de Lean Six Sigma (DMAIC, SIPOC, muda, Kaizen, takt time…) tienen su propio [glosario LSS](/lean-six-sigma/glosario.md).

| Término | Definición | Unidad |
|---|---|---|
| **4 P (Marketing Mix)** | Product, Place, Price, Promotion: producto, lugar, precio y promoción. Concepto clásico del PM de la era del marketing. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **5 Porqués** | Técnica de preguntar "¿por qué?" sucesivamente para llegar a la causa raíz de un problema. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **A/B Testing** | Experimento que compara dos versiones (A y B) con usuarios reales para ver cuál funciona mejor. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Agile / Agilidad** | Forma de trabajo basada en el Manifiesto Ágil: iterar, poner a las personas en el centro, entregar valor temprano y con calidad. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Anti patrón** | Mala solución para un problema, también llamada trampa (por ejemplo, reinventar la rueda). | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Assumption Grid** | Cuadrante para priorizar supuestos según su importancia y cuánto sabemos de ellos. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **B2B / B2C / C2C** | Business to Business, Business to Consumer y Consumer to Consumer: tipos de mercado según quién vende y quién compra. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Brand Men** | Responsables de marca descritos por Neil McElroy en P&G (1931): el origen del Product Management. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Build, Measure, Learn** | Ciclo Lean: construir (MVP), medir y aprender para iterar. | [Clase 11/11](/modulo-1/unidad-1/clase-11-11.md) |
| **CAC** | Customer Acquisition Cost: costo de conseguir un cliente nuevo. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Cliente** | Quien compra el producto (puede no ser quien lo usa). | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Cocreación de valor** | Idea de que el valor no lo genera solo el proveedor, sino el proveedor junto con el consumidor. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Cohorte** | Grupo de usuarios que comparte un momento de inicio (por ejemplo, los que se registraron en la misma semana), usado para medir retención. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Customer-centric** | Enfoque centrado en el cliente: el PM como voz del consumidor dentro de la compañía. | [Clase 11/11](/modulo-1/unidad-1/clase-11-11.md) |
| **Ciclo de vida del producto** | Etapas de un producto: desarrollo, introducción, crecimiento, madurez, declive y retiro. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Elevator Pitch** | Template para escribir una propuesta de valor: PARA, QUIENES NECESITAN, LA/EL, ES, QUE, A DIFERENCIA DE, NUESTRO PRODUCTO. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Empathy Map** | Mapa de empatía: herramienta de Design Thinking con lo que el usuario piensa, ve, dice, oye, sus esfuerzos y resultados. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Encuesta** | Técnica cuantitativa para saber cuántas veces se repite una situación; va después de las entrevistas. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Entrevista** | Técnica cualitativa para entender en profundidad el contexto y la necesidad del usuario target. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Esencias ágiles** | Según la cátedra: Iteraciones, Individuos, Valor Temprano y Calidad. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Factibilidad** | Evaluación de viabilidad de un producto: operativa, tecnológica, de costos, de cronograma y madurez del mercado. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Feature Factory** | Anti patrón: llenar el producto de funcionalidades sin evaluar para qué ni para quién. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Feedback Grid** | Herramienta para obtener y clasificar el feedback de usuarios (gustó, críticas, preguntas, ideas). | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Full Quality** | Anti patrón: aplicar máxima calidad a todo en vez de calidad adecuada. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Hipótesis** | Suposición a validar. En el Lean UX Canvas: "Creemos que [resultado] si [usuario] obtiene [beneficio] con [característica]". | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Lean** | Paradigma surgido del Toyotismo que busca quedarse solo con lo que genera valor al usuario final. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Lean Startup** | Enfoque de Eric Ries para validar hipótesis de negocio con experimentos de bajo costo (MVP y Build, Measure, Learn). | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Lean UX Canvas** | Canvas de 8 bloques (Gothelf) para definir un producto desde el problema de negocio hasta el experimento mínimo. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **LTV** | Lifetime Value: valor que deja un cliente durante toda su relación con el producto. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Mago de Oz** | Técnica de experimento en la que el usuario cree usar un producto automatizado, pero detrás hay personas haciéndolo a mano. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Manifiesto Ágil** | Declaración de 2001 (Snowbird, Utah, 17 firmantes) con 4 valores para el desarrollo de software. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Matriz BCG** | Clasificación de productos según crecimiento del mercado y participación relativa: Estrella, Interrogación, Vaca y Perro. | [Clase 11/11](/modulo-1/unidad-1/clase-11-11.md) |
| **Mentalidad ágil** | Cambio de paradigma: cocrear valor, sumar al usuario, aceptar la incertidumbre y maximizar el aporte humano. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Mercado objetivo** | El segmento de usuarios al que apunta el producto. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **MVP** | Minimum Viable Product: la versión mínima de un producto que permite aprender de usuarios reales. | [Clase 11/11](/modulo-1/unidad-1/clase-11-11.md) |
| **Navaja Victorinox** | Anti patrón: un producto que hace de todo y nada con excelencia. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **P&L** | Profit & Loss: estado de ganancias y pérdidas de un producto. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **PMF (Product Market Fit)** | Estado en que el producto resolvió el problema de sus usuarios target (Problem Solution Fit) y es económicamente viable. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **PRD** | Product Requirements Document: documento que concentra el análisis previo a decidir crear un producto. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Problem Solution Fit** | Momento en que se validó que el producto resuelve el problema de los usuarios target. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Producto** | Conjunto de atributos tangibles e intangibles percibidos como valor, que es una forma de resolver un problema. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Producto digital** | Producto no físico, construido y comercializado con tecnologías de la información (apps, streaming, eBooks, cursos online). | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Product Canvas** | Herramienta de Roman Pichler que resume el producto: nombre, objetivo, métricas, segmento target, Big Picture y detalle. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Product Manager** | Máximo responsable de todo lo que concierne al producto, incluido su equipo. En la intersección de UX, Data, Tecnología y Business. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Product Owner** | Rol de Scrum que originalmente actúa como nexo entre el negocio y el equipo. La cátedra considera esa visión atrasada. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Propuesta de valor** | Promesa de los resultados y beneficios que el producto le dará al usuario; tiene un aspecto emocional y uno funcional. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Proxy Product Manager** | Anti patrón: un PM que en realidad es intermediario entre quienes deciden y el equipo. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Retención** | Capacidad del producto de que los usuarios sigan usándolo en el tiempo. Foco del PM en la madurez. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Scary questions** | Preguntas difíciles sobre la visión: ¿por qué no se hizo aún? ¿Quién pagaría? | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Scrum** | El marco de trabajo ágil más difundido. No es sinónimo de Agile. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Segmento target** | Grupo de usuarios en el que se hace foco en un momento dado. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Síndrome Steve Jobs** | Creer que uno mismo es el usuario del producto. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Software Primero** | Mirada digital: pensar que el software está embebido en casi todo y suele ser la ventaja competitiva. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Time to Market** | Tiempo desde que se detecta una necesidad hasta que la solución está disponible en el mercado. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Usuario** | Quien usa el producto (puede no ser quien lo compra). | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Valor** | La percepción de un beneficio, una utilidad o una importancia de algo. Es subjetivo. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Valores ágiles** | Según la cátedra: Coraje, Comunicación, Retroalimentación y Simplicidad. | [M1·U1](/modulo-1/unidad-1/README.md) |
| **Visión de producto** | El destino del producto: grande, compartida, inspiradora y concisa. | [M1·U2](/modulo-1/unidad-2/README.md) |
| **Zombie Feature** | Anti patrón: funcionalidad sin uso real que nunca se retira. | [M1·U1](/modulo-1/unidad-1/README.md) |

> Cuando se libere una unidad nueva, sumá sus términos acá manteniendo el orden alfabético.
